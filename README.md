# 2026 교육활동 웹진

시나브로의 왼쪽 메뉴와 주제별 색상을 참고한 교육활동 웹진입니다.

- index.html: 웹진 첫 화면과 분야별 목록, 반응형 본문
- app.js / data.js / webzine.css / editorial.css: 화면 기능, 89편의 본문, 스타일
- thumbnails/: 플랫폼 실제 첫 화면과 글별 자료 미리보기
- fonts / hero / img1 / img2 / qr: 글꼴과 원문 이미지

압축을 푼 뒤 index.html을 열면 바로 볼 수 있습니다. 인터넷 없이 본문과 사진을 읽을 수 있고, 외부 플랫폼 링크는 인터넷이 필요합니다.

GitHub Pages에는 이 폴더의 내용 전체를 같은 구조로 업로드하세요. index.html이 저장소 최상위에 있어야 합니다. Settings > Pages에서 게시할 브랜치와 폴더를 지정합니다. 기존 파일이 있다면 교체 전에 백업하세요.

웹진은 #section/classroom 같은 주제 링크와 #article/16 같은 본문 링크를 지원합니다. 원문 보고서 보기와 다운로드 기능은 포함하지 않습니다.

내용 기준일은 원문과 동일한 2026년 10월 7일입니다. 수치·활동 상태는 원문의 기록을 유지했습니다. 검색엔진 노출 제한 설정도 유지했습니다.
